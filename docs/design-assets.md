## Brand Harmonization Guidelines
- All vector SVG illustrations utilize SVG gradients mapped to American FutureTech CSS custom variables:
  - Deep Forest Green: `#1a361d` (Fill: `url(#aft-forest-grad)`)
  - Precision Emerald: `#10b981` (Fill: `url(#aft-emerald-grad)`)
  - Warm Canvas Accent: `#fafaf9` / `#fffff2`
  - Velvet Berry Accent: `#9e4f8f`
- Stroke widths are standardized to `1.5px` and `2px` with round line-caps for an editorial, human-centric aesthetic.
- Subtle animations adhere to `4–7s` ease-in-out floating keyframes with reduced-motion fallbacks.
