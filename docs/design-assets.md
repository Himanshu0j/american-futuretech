## 3. Brand Harmonization Guidelines
- All vector SVG illustrations are customized to American FutureTech brand colors:
  - Deep Forest Green: `#1a361d` (primary character structure & elements)
  - Precision Emerald / Mint: `#10b981` / `#76ff8a` (action highlights, screens, code accents)
  - Velvet Berry: `#9e4f8f` (technology pathways & specialty tracks)
  - Amber Gold: `#f59e0b` (accreditation badges & certifications)
- Framer Motion animation loops adhere to gentle `4–8s` ease-in-out floating keyframes with reduced-motion support.
